## 이 파일은 무엇인가

모델 변경 실험을 기록하기 위한 템플릿입니다.

아직 모델 변경 실험은 진행하지 않았습니다. baseline 또는 기존 최고 실험과 비교해 새 모델이 실제로 도움이 되는지 판단하기 위해 사용합니다.

## 실험 목적

- 기존 모델 대비 새 모델의 validation 성능을 비교합니다.
- 학습 시간, 추론 시간, 구현 복잡도를 함께 기록합니다.
- 단순 점수뿐 아니라 오류 유형 개선 여부도 확인합니다.

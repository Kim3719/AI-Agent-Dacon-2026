# configs 폴더

학습과 추론에 사용할 설정 파일을 모아두는 곳입니다.

설정 파일에는 아래 내용을 적습니다.

- 어떤 데이터 경로를 쓸지
- 어떤 모델을 쓸지
- 어떤 피처를 쓸지
- seed 값은 무엇인지
- 결과를 어디에 저장할지

## 왜 필요한가요?

코드 안에 설정값을 직접 쓰면 나중에 실험을 재현하기 어렵습니다.

예를 들어 `EXP003` 점수가 좋았는데 어떤 파라미터였는지 기억이 안 나면 다시 만들 수 없습니다.

그래서 실험마다 설정 파일을 남깁니다.

## 사용 예시

```bash
python scripts/run_train.py --config configs/EXP001_baseline.yaml
```

새 실험을 만들 때는 `exp_template.yaml`을 복사해서 사용합니다.

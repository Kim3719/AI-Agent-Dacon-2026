# 초보자를 위한 용어

- **Macro-F1:** 클래스별 F1을 동일한 비중으로 평균한 값입니다. 표본이 적은 클래스도 중요하게 평가합니다.
- **Validation:** 모델 개발 중 성능을 확인하기 위해 학습 데이터와 분리한 평가 영역입니다.
- **Public score:** 대회 서버의 공개 평가 데이터에서 계산된 점수입니다.
- **Data leakage:** 평가 시점에는 알 수 없어야 할 정보가 학습 또는 튜닝 과정에 들어가는 문제입니다.
- **Group split:** 같은 세션처럼 서로 연관된 표본이 Train과 Validation 양쪽에 섞이지 않도록 그룹 단위로 분리하는 방법입니다.
- **Knowledge Distillation:** 큰 Teacher 모델의 확률 분포를 작은 Student 모델이 학습하는 방법입니다.
- **FGM:** 임베딩에 작은 적대적 변화를 추가해 모델이 작은 변화에 덜 민감하도록 학습하는 방법입니다.
- **LLRD:** 위쪽 레이어에는 큰 학습률을, 아래쪽 레이어에는 점차 작은 학습률을 적용하는 방법입니다.
- **OOF:** 각 표본을 학습에 사용하지 않은 Fold의 모델로 예측해 얻은 결과입니다.
- **Ensemble:** 여러 모델의 예측을 결합하는 방법입니다.
- **Ablation:** 구성 요소를 하나씩 제거하거나 변경하여 실제 기여를 확인하는 실험입니다.
- **Margin:** 가장 높은 예측 확률과 두 번째 확률의 차이입니다. 작을수록 모델이 두 후보 사이에서 확신하지 못한다는 뜻입니다.

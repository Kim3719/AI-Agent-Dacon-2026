# 먼저 읽어주세요

이 저장소는 저의 **첫 AI 경진대회 학습 기록**입니다.

처음에는 좋은 모델을 사용하고 점수를 올리는 것이 대회의 핵심이라고 생각했습니다. 하지만 실제로는 데이터가 어떻게 나뉘었는지, Validation 결과를 믿을 수 있는지, 모델이 왜 틀리는지, 학습과 제출 코드가 같은지를 확인하는 일이 더 중요했습니다.

그래서 이 저장소는 성공한 최종 모델만 남기지 않습니다. 초기 `0.6XXX` 제출, 성능이 오르지 않은 실험, 좋아 보였지만 누수였던 결과, 모델 파일 덮어쓰기, 학습·추론 입력 불일치, 최종 `0.7776644`까지의 과정을 함께 기록합니다.

## 모든 실험을 설명하는 공통 질문

1. **어떤 문제가 있었는가?** 관찰과 증거를 먼저 적습니다.
2. **왜 이 방법을 선택했는가?** 문제와 방법 사이의 연결을 설명합니다.
3. **어떻게 적용했는가?** 변경한 입력, 코드, 설정과 통제 변수를 기록합니다.
4. **결과가 어땠는가?** Validation과 Public 결과를 가능한 범위에서 구분합니다.
5. **왜 성공하거나 실패했는가?** 단순한 점수 나열을 넘어 원인을 분석합니다.
6. **다음에는 어떻게 활용할 것인가?** 다음 실험과 후속 연구로 연결합니다.

이 여섯 질문이 이 Repository의 가장 중요한 작성 원칙입니다.

## 문서 지도

| 단계 | 질문 |
|---|---|
| Step 01 | 우리가 해결한 문제와 데이터는 무엇인가? |
| Step 02 | 첫 제출과 Baseline은 어디에서 시작했는가? |
| Step 03 | 모델에게 어떤 정보를 어떻게 보여줬는가? |
| Step 04 | 모델은 어디에서, 왜 틀렸는가? |
| Step 05 | 높은 Validation 점수를 정말 믿을 수 있는가? |
| Step 06 | 복잡하거나 큰 모델은 실제로 도움이 되었는가? |
| Step 07 | Label noise에 덜 흔들리게 학습할 수 있는가? |
| Step 08 | 서로 다르게 틀리는 모델을 어떻게 결합했는가? |
| Step 09 | 코드는 버전별로 어떻게 발전했는가? |
| Step 10 | 실험을 어떤 기준으로 기록하고 비교했는가? |
| Step 12 | 이 첫 대회가 다음 연구의 거름이 된 이유는 무엇인가? |

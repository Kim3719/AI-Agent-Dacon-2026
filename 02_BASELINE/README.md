# Step 02. 첫 제출과 Baseline은 어디에서 시작했는가?

## 어떤 문제가 있었는가

첫 제출 점수는 `0.6XXX`였습니다. 점수를 개선하려면 새로운 기법보다 먼저 모든 실험이 비교될 기준 모델이 필요했습니다.

## 왜 이 방법을 선택했는가

한국어와 영어, 코드 관련 문자열이 섞인 입력을 처리하기 위해 XLM-RoBERTa Base를 선택했습니다. 작은 모델은 Large보다 반복 실험이 빠르고 1GB 제출 제한에도 대응하기 쉬웠습니다.

## 어떻게 적용했는가

- XLM-R `[CLS]` 표현과 수치 메타피처를 결합했습니다.
- History를 시간순으로 직렬화하고 Current Prompt를 포함했습니다.
- 초기 메타피처는 정규화된 `turn_index`였습니다.
- 클래스 불균형을 고려해 class-weighted cross entropy를 사용했습니다.
- 동일 설정에서 이후 버전과 비교할 수 있도록 Macro-F1과 클래스별 F1을 저장했습니다.

## 결과가 어땠는가

확인된 첫 연구 Baseline은 Validation Macro-F1 약 `0.7412`였습니다. `read_file`, `grep_search`, `list_directory`, `glob_pattern` 네 클래스의 F1이 상대적으로 낮았습니다.

## 왜 성공하거나 실패했는가

사전학습 언어모델은 전체 의도를 이해하는 데 도움이 됐지만, 비슷한 도구 행동을 가르는 구조적 신호까지 명확히 표현하지 못했습니다. Baseline 자체의 가장 큰 성공은 높은 점수가 아니라 이후 실험의 비교 기준과 주요 오류군을 제공한 것입니다.

## 다음에는 어떻게 활용할 것인가

새 프로젝트에서도 가장 먼저 작고 재현 가능한 Baseline을 만들고, 이후 모든 실험이 같은 Split과 Metric에서 이를 이기는지 확인합니다.

# results 폴더 안내

이 폴더는 실험 결과물을 저장하는 공간입니다.

## 구조

| 경로 | 설명 |
| --- | --- |
| `figures/` | EDA 그래프, confusion matrix, feature importance 등 이미지 저장 |
| `submissions/` | DACON 제출용 CSV 또는 zip 파일 저장 |

## 현재 상태

아직 실제 실험 결과는 없습니다. README에서 깨진 이미지가 보이지 않도록 placeholder SVG만 추가되어 있습니다.

## 사용 원칙

- 결과 파일 이름에는 실험 ID를 포함합니다. 예: `exp01_confusion_matrix.png`
- 제출 파일은 어떤 실험에서 생성됐는지 `experiments/` 문서에 링크합니다.
- 큰 결과 파일은 GitHub 업로드 여부를 별도로 판단합니다.

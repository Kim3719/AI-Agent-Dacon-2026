# data 폴더 안내

이 폴더는 DACON에서 제공한 데이터와 전처리 결과를 관리하는 위치입니다.

## 권장 구조

```text
data/
|-- raw/
|   |-- train.jsonl
|   |-- train_labels.csv
|   |-- test.jsonl
|   `-- sample_submission.csv
|-- interim/
`-- processed/
```

## 각 폴더의 의미

| 경로 | 설명 | Git 업로드 여부 |
| --- | --- | --- |
| `raw/` | DACON에서 받은 원본 파일을 그대로 둡니다. | 업로드하지 않음 |
| `interim/` | EDA나 전처리 중간 결과를 임시로 저장합니다. | 보통 업로드하지 않음 |
| `processed/` | 학습에 바로 사용할 수 있게 가공한 데이터를 저장합니다. | 파일 크기와 규칙에 따라 결정 |

## 현재 상태

아직 원본 데이터는 이 저장소에 포함하지 않았습니다. 데이터 파일은 로컬에서 관리하고, 필요한 경우 대회 규칙에 맞춰 경로만 문서화합니다.

## 주의사항

- 대회 데이터의 재배포 가능 여부를 확인하기 전까지 원본 데이터를 GitHub에 올리지 않습니다.
- 대용량 파일은 Git이 아니라 로컬 디스크, 클라우드 스토리지, 또는 DVC 같은 도구 사용을 검토합니다.

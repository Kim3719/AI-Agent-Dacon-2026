# Step 10. 실험을 어떻게 기록할 것인가?

실험은 점수 한 줄이 아니라 의사결정의 근거입니다. 모든 실험은 아래 여섯 질문과 출처 구분을 사용합니다.

## 필수 질문

1. 어떤 문제가 있었는가?
2. 왜 이 방법을 선택했는가?
3. 어떻게 적용했는가?
4. 결과가 어땠는가?
5. 왜 성공하거나 실패했는가?
6. 다음에는 어떻게 활용할 것인가?

## 출처와 기여 구분

1. 참고한 논문
2. 기술 문서
3. 공개 구현
4. 제안자 — 이 프로젝트에서는 제 제안이 대부분
5. 직접 변형한 부분
6. 실제 실험 결과와 원본 산출물

## 기록 원칙

- Validation과 Public 점수를 다른 열로 기록합니다.
- 서로 다른 클래스 수나 Split의 점수를 직접 비교하지 않습니다.
- 성공 여부와 별개로 가설과 결과를 남깁니다.
- 유실된 값은 `unknown`, 실행하지 않은 값은 `not run`으로 구분합니다.
- 작은 개선은 Seed 또는 Split 반복 없이 확정하지 않습니다.
- Config, 코드 버전, 데이터 버전, 산출물 위치를 함께 연결합니다.

새 실험은 [`EXPERIMENT_TEMPLATE.md`](EXPERIMENT_TEMPLATE.md)를 복사해 작성합니다.
